# LuxeCars

Landing page statique (HTML/CSS) pour une vitrine de véhicules de luxe.

## Lancer

- Ouvrir `index.html` dans un navigateur.

## Améliorations intégrées

- Meilleures perf perçues : `preconnect`/`preload`, images `loading="lazy"`, dimensions renseignées (moins de CLS).
- Accessibilité : lien “skip”, labels de formulaire, ARIA sur la navbar et le toggle de thème.
- UI/UX : typographie moderne, couleurs via variables CSS, cartes mieux contrastées + dark mode plus cohérent.
